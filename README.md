# Tetris-in-Python

This is a program which runs a primitive version of Tetris in the Python language. The files use the Pygame module to help the game run smoothly. Other than that, the application was programmed from the ground up.

## Setup

1. After downloading the files, make sure they all stay in that folder.
2. Go into your computer's terminal and navigate to the folder using `cd <folder_name>`
3. Once there, use `pip install pygame` to install the module onto your computer.

After that you should be all good to start playing. To start a game, type into your terminal `python Tetris.py`. This should open up to the starting screen.

## Playing the Game

The controls for the game are pretty simple. to move the blocks, use the Left and Right Arrow keys. To speed the blocks up manually, use the Down Arrow key. To rotate the blocks, use the Up Arrow key. To pause, press the P key.

The overall speed and level will increase with every 1000 points you accumulate. You get 100 points for every line clear.

[Pygame documentation](https://pypi.org/project/pygame/)
